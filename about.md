# Editor Hotbar
Adds a customizable hotbar to the editor in which you can add frequently used objects. Keybinds and the hotbar color are also customizable in the mod's settings.

# Compatibility
This mod has been tested with both [BetterEdit](mod:hjfod.betteredit) and [Tinker](mod:alphalaneous.tinker). Please report any compatibility issues if found (see below)
